A two-sentence horror story for make.fun's "Two-Sentence Horror" bounty: a parent dismisses a child's warning about a whispering closet and moves her into the parents' bed — then the whispering follows, and it knows the name of the daughter the family buried last spring. The program writes the story (exactly two sentences, 230 characters) to `entry.txt`, validating the gate (1–400 characters, exactly two sentences) before writing.

## Run it

```sh
node main.ts
```

`main.ts` writes the story to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Node 22+, standard library only, no network, fully deterministic.
